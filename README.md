# ASCII Wallpaper Generator

Generate wallpapers from ASCII or braille art directly in your browser — no install, no dependencies.

**[Open the app](https://alejandrominor.github.io/ascii-to-wallpaper/)**

## Features

- Paste any ASCII or braille art and export it as a wallpaper
- Multiple built-in resolutions and orientations — landscape, portrait, and square (FHD, 2K, 4K, and more)
- Controls: font family, font size, text color, background color, alignment, line height, scanlines effect
- Clear and Paste buttons on the text area (Clipboard API, works on mobile)
- Fullscreen modal preview before downloading
- Exports as PNG at native resolution

## Usage

Open the [live app](https://alejandrominor.github.io/ascii-to-wallpaper/), paste your ASCII art, adjust the controls, and click **Download PNG**.

To run locally just open `index.html` in any browser.
